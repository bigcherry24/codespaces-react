컴포넌트, JSX와 props

화면을 재사용 가능한 단위로 나누고, 부모가 자식에게 데이터와 동작을 전달하는 방법을 익힙니다.

핵심: 컴포넌트 · JSX · props부모 → 자식

이번 회차의 목표

  • 함수 컴포넌트가 UI 조각을 반환하는 방식 이해
  • JSX의 표현식과 속성 규칙 이해
  • props로 값을 전달하고 callback으로 사용자 행동을 부모에게 알리는 흐름 이해

코드 따라가기

App.jsx는 달력과 일별 일정을 배치하고, 입력 UI를 ScheduleDialog.jsx에 위임합니다. 부모는 `schedule`, `onClose`, `onSave`를 props로 전달합니다.

<ScheduleDialog
  schedule={dialogSchedule}
  onClose={() => setIsDialogOpen(false)}
  onSave={saveSchedule}
/>

JSX 중괄호 안에는 JavaScript 표현식을 쓸 수 있습니다. 컴포넌트 이름은 대문자로 시작하고, 반환할 요소가 여러 개면 하나의 부모 요소로 감쌉니다.

진행 순서

  1. 5분: 현재 화면을 달력·일정 목록·모달로 나눠봅니다.
  2. 10분: 함수 컴포넌트와 JSX의 기본 규칙을 확인합니다.
  3. 15분: 부모가 모달에 전달하는 props를 표시합니다.
  4. 15분: 모달에서 `onSave`가 호출되는 경로를 추적합니다.
  5. 5분: 데이터 전달 방향을 화살표로 정리합니다.

실습

모달의 제목을 prop으로 받도록 바꾸거나, `ScheduleDialog`에 전달되는 prop 하나를 잠시 제거해 오류가 어디에서 드러나는지 관찰하세요.

마무리 질문

  • props는 어느 방향으로 전달되나요?
  • 자식 컴포넌트는 저장 결과를 어떻게 부모에게 알리나요?
  • JSX 중괄호에는 어떤 값이나 식을 넣을 수 있나요?
