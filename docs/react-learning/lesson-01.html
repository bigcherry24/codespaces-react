SESSION 01 · 45–60 MIN

React 앱의 시작과 렌더링

브라우저가 HTML을 읽고 React가 앱을 화면에 그리기까지, 진입 경로를 따라갑니다.

핵심: root · createRoot · render코드 읽기부터 시작

이번 회차의 목표

  • HTML 문서와 React 앱의 역할을 구분합니다.
  • `index.jsx`에서 `App`이 화면에 연결되는 흐름을 설명합니다.
  • `StrictMode`가 개발 중 어떤 도움을 주는지 이해합니다.

코드 따라가기

프로젝트는 index.html에서 시작합니다. `#root`라는 빈 요소가 React가 화면을 넣을 자리입니다. HTML이 src/index.jsx를 불러오고, 여기서 React DOM이 `App`을 root에 렌더링합니다.

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<React.StrictMode>
  <App />
</React.StrictMode>);

`App`은 실제 화면을 구성하는 컴포넌트입니다. React는 JSX를 브라우저가 이해하는 DOM으로 바꾸어 표시합니다.

진행 순서

  1. 5분: 화면에서 보이는 요소를 나열하고 어디서 오는지 추측합니다.
  2. 10분: HTML의 `#root`, 모듈 script, `createRoot`를 확인합니다.
  3. 15분: import 경로를 따라 `App.jsx`까지 이동합니다.
  4. 15분: 제목 문구를 바꾸고 브라우저 갱신을 관찰합니다.
  5. 5분: 앱 시작 흐름을 화살표로 설명합니다.

실습

`App.jsx`의 제목 텍스트를 바꾸고 저장합니다. 어떤 파일이 바뀌었는데 브라우저에는 왜 즉시 반영되는지 말로 정리해 보세요.

마무리 질문

  • 브라우저가 처음 읽는 파일은 무엇인가요?
  • `#root`는 어떤 역할을 하나요?
  • `App`은 어디에서 root에 전달되나요?
