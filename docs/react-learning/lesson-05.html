SESSION 05 · 45–60 MIN

폼과 제어 컴포넌트

폼 입력값의 주인을 React state로 두고, 값 변경·검증·제출까지 한 흐름으로 연결합니다.

핵심: value · onChange · validation사용자 입력

이번 회차의 목표

  • input의 `value`와 React state가 동기화되는 방식 이해
  • 공통 change handler와 `name` 속성의 역할 이해
  • submit 이벤트에서 입력값을 검증하고 정리

코드 따라가기

ScheduleDialog.jsx는 `form` state를 입력 필드에 전달합니다. `onChange`에서는 필드 이름에 맞는 값 하나만 갱신하고, 제출 handler는 제목·날짜·시간을 검증합니다.

const { name, value, type, checked } = event.target;
setForm((currentForm) => ({
  ...currentForm,
  [name]: type === 'checkbox' ? checked : value,
}));

제어 컴포넌트에서는 state가 입력값의 기준입니다. state가 바뀌면 value가 갱신되고, 사용자의 입력도 handler를 거쳐 state로 돌아옵니다.

진행 순서

  1. 5분: 모달의 필드와 데이터 구조를 짝지어 봅니다.
  2. 10분: `value`와 `onChange`가 함께 있는 이유를 확인합니다.
  3. 15분: 공통 handler에서 `name`으로 값을 선택하는 방식 추적
  4. 15분: 제목을 비우거나 종료 시간을 앞당겨 검증 확인
  5. 5분: 입력에서 onSave 호출까지 설명합니다.

실습

마무리 질문

  • 입력 요소의 현재 값을 최종적으로 관리하는 곳은 어디인가요?
  • `name` 속성이 공통 handler에서 하는 일은 무엇인가요?
  • 검증이 통과하지 않으면 onSave는 호출되나요?
